# 520 手写证明 · 动图

- `520手写证明_动图.mp4`：1440×1080，60 帧，7.5 秒，带音乐，可循环
- `520手写证明_封面.jpg`：静止那一帧，可以当封面或单独发图

内容照参考动图：

- 图形：四边形 DCBA，对角线交于 O，外面一圈虚线 L、V、e
- 证明：∵ 我喜欢你 ∴ ∠L + ∠O + ∠V + ∠e = 520° ∴ Love = 520

画面是重新做的，没有用别人的原图：

- 横线本、手写字迹、教辅书和练习卷都是自己画的
- 上面那道函数题、底下的书页和卷子内容都是新写的
- 用手机斜拍的角度渲染，有窗光、手的阴影、远处虚化、背面透字和手机噪点

动起来的方式模仿实况照片：

- 先静止约 3 秒
- 然后像手机刚抬起来一样往后拉、再推近，带一点手抖
- 最后停回静止画面，可以循环

音乐是我写的一小段八音盒旋律，没有版权问题。发抖音时也可以换成你自己选的歌。

`脚本/`：

- `build_scene.py`：画纸面和桌面场景
- `render.py`：相机视角和动图效果
- `music.py`：音乐
