# 王者击杀秀 · 如果可以

成片：`王者击杀秀_如果可以.mp4`（1920×1080，60 帧，79 秒）

- 素材：4 段对局录屏（345 / 346 / 347 / 348.mov）
- BGM：抖音视频里的《如果可以》DJ 版
  - 抖音那段视频加速了 1.1 倍，实际速度是 145 BPM（一拍 0.413 秒）
  - 所有剪辑点和击杀都对在这个节拍上
- 画面里只有王者原画面，没有加歌词、几杀之类的文字

## 结构

| 时间 | 音乐 | 画面 |
| --- | --- | --- |
| 0:00–0:03 | 开头「如果可以」 | 348 团战开团慢放，从黑场渐亮；再接 4 个一拍一闪的高光预告 |
| 0:03–0:26 | 第一段 | 7 个单杀（347 四个、348 三个），击杀都落在小节重拍上。5 个快进直接打过去，2 个慢放 |
| 0:24–0:26 | 第一段的上扬 | 越来越大的放大和径向模糊，冲进 drop |
| 0:26–0:38 | drop 1 | 346 三连决胜：前两杀原速，第三杀慢放 |
| 0:38–0:51 | 第二段 | 345 三连决胜，全程原速 |
| 0:51–0:53 | 第二段的上扬 | 348 冲进最后一波团战，2 倍多速 |
| 0:53–1:16 | 最后一段 | 348 四连超凡：前三杀原速连打，第 4 杀落在全曲最重的 1:06 并慢放；第 5 个人头打出团灭 |
| 1:16–1:19 | 结尾 | 慢放到几乎定格，褪色，淡出 |

## 用到的效果

| 效果 | 做法 |
| --- | --- |
| 变速 | 曲线变速，冲刺 1.5–2.4 倍；大部分击杀原速或快速直接过，只有 4 个高光降到 0.2 倍慢放 |
| 补帧 | 原录屏 30 帧，用光流补到 60 帧，慢放也不卡 |
| 卡点 | 每次击杀都落在鼓点上：放大冲击、闪白、RGB 色差，多杀更重 |
| 震屏 | 只在两个三杀的最后一杀和四杀那一下轻震，其他地方不震 |
| 节奏 | drop 里每个鼓点轻微放大，每小节轻闪一下 |
| 转场 | 镜头之间用径向模糊转场，两个 drop 用闪白 |
| 调色 | 提饱和、提对比、暗角 |
| 声音 | 歌在最上面；游戏原声全程保留（比歌低约 6 dB），变速段用 WSOLA 变速不变调；多杀处加一记低频冲击音 |

`剪辑脚本/` 里是生成这个视频的 Python 脚本（OpenCV + FFmpeg）：

- `montage.py`：时间线、变速曲线和特效都写在这里
- `mix.py`：混音
