# 王者击杀秀 · 如果可以

成片：`王者击杀秀_如果可以.mp4`（1920×1080，60 帧，79 秒）

- 素材：4 段对局录屏（345 / 346 / 347 / 348.mov）
- BGM：抖音视频里的《如果可以》DJ 版
  - 抖音那段视频加速了 1.1 倍，实际速度是 145 BPM（一拍 0.413 秒）
  - 所有剪辑点和击杀都对在这个节拍上
- 画面里只有王者原画面，没有加歌词、几杀之类的文字

## 结构

| 0:24–0:26 | 第一段的上扬 | 慢慢推近加径向模糊，冲进 drop |

## 用到的效果

| 效果 | 做法 |
| --- | --- |
| 变速 | 曲线变速，冲刺 1.5–2.4 倍。大多数击杀原速或快进直接过，只有最燃的 5 下慢放（约 0.2 倍）：两个单杀、两个三杀的最后一杀、最后团灭那一杀。慢放从击中那一帧开始，马上弹回原速，最后团灭那一下一直慢到结尾 |
| 补帧 | 原录屏 30 帧，用光流补到 60 帧，慢放也不卡 |
| 卡点 | 每次击杀都落在鼓点上：轻微推近加一点 RGB 色差，多杀更重 |
| 闪白 | 只闪 5 次，而且都比较淡：两个 drop、两个三杀的第三杀、最后团灭那一杀 |
| 震屏 | 不震屏 |
| 转场 | 镜头之间用径向模糊转场 |
| 调色 | 提饱和、提对比、暗角 |
| 声音 | 游戏原声全程保留，和歌差不多一样大；变速段用 WSOLA 变速不变调；多杀处加一记低频冲击音 |

`剪辑脚本/` 里是生成这个视频的 Python 脚本（OpenCV + FFmpeg）：

- `montage.py`：时间线、变速曲线和特效都写在这里
- `mix.py`：混音

# 第三弹（参考抖音剪辑手法重剪）

成片：`王者击杀秀_第三弹.mp4`（1920×1080，60 帧，2 分 24 秒）

素材、BGM 和卡点跟第二弹一样，按你发的 5 个参考视频的剪法重新剪了一遍。

参考视频里有些地方不是特效，是手机剪辑时出的问题，没有照搬：

- 画面突然变灰、只剩彩色拖影的几帧
- 画面完全卡住不动、音乐还在走的长定格

参考视频末尾的英雄 CG 皮肤画面不是你的录屏，也没有用。

## 从参考视频里学的手法

| 手法 | 参考里的样子 | 这次用在哪 |
| --- | --- | --- |
| 白场过曝转场 | 画面越来越亮、径向模糊冲进白场，再切下一段 | 0:21、1:47 两次（只用这两次） |
| 甩镜运动模糊 | 画面横向甩出去，带红青色差 | 0:10、0:33、1:01、1:32、2:04 |
| 推近特写 | 打架时镜头推近到战场 | 每次击杀和助攻前后自动推近，打完拉回 |
| 辉光 + 暗调 | 技能特效发光，整体更暗更有对比 | 全片 |
| 运动模糊 | 快速变速时有拖影 | 所有超过 1.35 倍速的地方 |
| 变焦模糊转场 | 镜头冲进下一段 | 0:48、1:16 |
